I'm Vinay Agastya, founder and CEO of Ctruh, based in Bangalore.

Ctruh builds software for creating, publishing and sharing 3D. Teams in real estate, architecture, digital twins and product use it to put large 3D work in front of the people who need to see it, without an app or install.

Our work includes:

- **Verse**, our streaming 3D platform: upload a 3D file and get one link that opens in a browser
- **Verse Engine**, our own engine in Rust, compiled to WebAssembly and running on WebGPU with a WebGL fallback
- Plug-ins for Unreal, Unity, Blender and Substance 3D Painter, plus an SDK and API
